### 🔨 What I Build & Research

- **Applied LLM Systems & Tool Execution:** Designing Intermediate Representations (IRs) and deterministic execution layers so models declare structural intent while code handles computation.
- **Vision & Document Intelligence:** Fine-tuning specialized vision architectures (DocLayout-YOLO, YOLOv10m to 96.1% mAP50) for high-density document understanding and structured extraction.
- **Inference & Infrastructure:** High-throughput model routing, streaming SSE runtimes, GPU memory optimization, and custom kernel exploration (Triton).
